What IdealOne does

These are the modules running in the system today.

🛒Order intake (OMS)

  • Marketplace connections for Shopee, Lazada and TikTok via Zort and OneCart
  • Excel and GI file uploads
  • Skipped rows are held aside rather than silently dropped

📦Pick, pack & scan

  • Scan-verified picking and packing
  • Phone scanning with an offline queue that syncs once you're back online
  • Carton labels

🚛Inbound receiving

  • ASNs, scan-to-receive, batch and expiry capture
  • GRN and putaway
  • FEFO pick rotation (earliest expiry first)

📊Inventory & item master

  • Stock by client and location
  • Item master for each client

🗺Transport (TMS)

  • Map view and route planning
  • Driver app and run sheets
  • Address book

👤Client portal

  • Clients can view their own orders
  • New Order form that assigns order numbers automatically
  • Delivery order (DO) PDF

⚡Automation

  • Automatic ready-to-ship (RTS) handling
  • Matches shipping labels to orders
  • Outlet lookup for B2B paperwork

🔗Integrations & admin

  • Keyfields WMS integration
  • Admin features switched on per user

Built to scale

How IdealOne is designed to cope as clients and volume grow.

🏢Multi-client, multi-hub

Many clients and hubs run in one system, and each client's data is kept separate.

💾Incremental persist

A scan saves only the record that changed, so the whole database isn't rewritten each time.

🗃Hot / cold archive

Old records move to an archive, which keeps the live data set small.

🔍Server-side search

Order search runs on the server, so the browser doesn't have to load every order.

👥Concurrent users

Warehouse staff, drivers and clients can all work in the system at the same time.
